# Matched-settings GAMESS-XEDA comparison kit (2026-10-18)

Status: **EDA_GPU side computed; GAMESS-XEDA side not yet run.** No XEDA/GAMESS
installation exists on the development host, so EDA components remain externally
unvalidated until the logs below are produced and compared.

## What is here

- `gamess_inputs/*.inp` — one GAMESS input per case, generated by
  `scripts/xeda_matched.py prepare`. Keywords follow the official XEDA GAMESS manual
  (`$LMOEDA` MATOM/MCHARG/MMULT, `EDATYP=GKS`, `SUPBAS=.T.` counterpoise), with
  explicit `ISPHER`, `UNITS=BOHR` (coordinates converted with PySCF's Bohr constant
  0.52917721092 Å), `$DFT NRAD=150 NLEB=1202`, `ICUT=11 ITOL=30`, direct SCF, `CONV=1.0D-08`.
- `manifest.json` — EDA_GPU components (Eh) for every case, settings, preset tolerances.
- `<case>_<backend>/result.json` — full EDA_GPU results (fragment XYZ included).

Tolerances were fixed before any XEDA output existed. XEDA prints components to
1e-6 Eh, so differences below ~5e-7 Eh are unresolvable.

## Before trusting a comparison, check in each GAMESS log

1. **B3LYP variant.** The B3LYP cases assume GAMESS `DFTTYP=B3LYP` uses VWN5
   (PySCF `b3lyp5`). Confirm from the functional description printed in the log; if it
   reports VWN1/VWN-RPA, the B3LYP cases must be recomputed with PySCF `b3lyp`. PBE0
   cases have no such ambiguity and are the primary test.
2. **Spherical/Cartesian count.** The number of basis functions must match: water dimer
   cc-pVDZ 48, CO₂ dimer 6-31G* Cartesian 90, tryptamine–water aug-cc-pVDZ 425.
3. **Grid.** Confirm NRAD=150/NLEB=1202 were accepted (no warning or substitution).
4. **Counterpoise.** The decomposition table header should read `ALL BASIS SET`.
5. **SCF convergence** of supermolecule and every monomer.

## Run and compare

```bash
# on a machine with GAMESS + XEDA (adjust to your rungms version and core count)
for f in gamess_inputs/*.inp; do rungms "$f" 00 8 > "logs/$(basename "${f%.inp}").log"; done

# back in EDA_GPU
.env/bin/python scripts/xeda_matched.py compare \
  --manifest reports/xeda_matched_2026-10-18/manifest.json \
  --logs <directory with the five .log files> \
  --output reports/xeda_matched_2026-10-18/comparison.json
```

The compare step fails loudly if a log has no decomposition table. Please keep the
GAMESS logs; they can be added here as attributed reference data.
